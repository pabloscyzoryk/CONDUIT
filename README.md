# CONDUIT

Telegram signal processing, trade management, and research tools for MetaTrader 5.

The maintained source is in [CONDUIT](CONDUIT/README.md). GOD-X7 remains the
default preset by the owner's decision. Ongoing research does not automatically
promote another candidate to GOD-X8. The September 8 update adds Real Drawdown
and more precise execution diagnostics; see the
[release notes](CONDUIT/docs/RELEASE_2026-09-08_GOD-X7_RDD.md).
The follow-up adds [live session replay](CONDUIT/docs/LIVE_REPLAY.md) and
reconciles rearm counters after an uncertain broker acknowledgement.

Private installations, credentials, Telegram sessions, market/chat data, old Git
history, compiled outputs, and local research artifacts are excluded from this
repository. Configure an installation with your own credentials using the
documented examples.

Historical simulation results are not a guarantee of future returns.
